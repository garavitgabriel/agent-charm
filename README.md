# Dex Charm

A pocket device with Dex on it: an always-animated pixel character on a 1.8" AMOLED (Waveshare
ESP32-S3-Touch-AMOLED-1.8 V2). You hold to talk to Dex, glance at what's pending, and tap to decide.
It's a remote and a face for the agents the owner already runs.

Status: **pre-design.** Nothing is built yet. Start with [`docs/BRIEF.md`](docs/BRIEF.md).
